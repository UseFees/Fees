# Glossary

- **ALT** — Solana Address Lookup Table.
- **bps** — basis points; 10,000 bps = 100%.
- **epoch** — FEES hourly accounting/execution interval.
- **module** — selected behavior receiving the 90% allocation.
- **sharing_config** — Pump fee-sharing configuration used by the verified path.
- **buyback bucket** — 10% allocation reserved for FEES buyback/burn.
- **canary** — deliberately small production transaction.
- **receipt** — persisted execution/accounting evidence.
