# Economics

Top-level creator-fee split:
- **9000 bps (90%)** → selected module
- **1000 bps (10%)** → FEES buyback/burn bucket
- **0 bps** → extra protocol percentage

All accounting uses integer base units.

Dust may carry forward when execution is uneconomical. Carry-forward changes timing, not percentages.

The 10% buyback path is intentionally inert until the real `$FEES` mint and production swap/signer route are ready.
