# Transparency

This repository separates **verified facts**, **planned behavior**, and **future work**.

## Verified facts
Current evidence supports a local-mainnet-clone launch flow with 9000/1000 sharing, split-before-buy ordering, post-launch immutability, retry-safe confirmation, duplicate protection, and hourly 90/10 accounting.

## Planned behavior
The product defines ten module families. Documentation for a module is not evidence that the module is live. The API registry is the runtime source for enabled modules.

## Explicitly incomplete
- Real `$FEES` mint: not provided.
- Mainnet buyback/burn: not enabled.
- Real swap provider: not wired.
- Third-party audit: not completed.
- Mainnet canary: not completed.

## Evidence policy
Status claims should be backed by transaction signatures, immutable on-chain state, reproducible test output, commit SHAs, receipts, or postmortems.

Marketing copy is not evidence.
